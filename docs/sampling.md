# 自适应采样与随机移位 Sobol 的数学原理

## 实现范围

1. 主积分器改为迭代形式，维护辐射亮度与路径权重，修正俄罗斯轮盘补偿。
2. BVH 缓存包围盒、确定性最长质心轴分割、单物体叶子只求交一次、近子树优先、复用方向倒数。
3. 每像素自适应采样，使用实际样本数归一化。
4. 相机五维使用数字随机移位 Sobol：像素内 x/y、镜头 x/y、快门时间。后续散射和轮盘仍使用独立的伪随机数。

没有实现完整路径维度 Sobol、完整 Owen scrambling、NEE、SAH、GPU 或降噪。

## 1. 路径积分和俄罗斯轮盘

对采样出的方向，路径权重更新为

$$\beta_{k+1}=\beta_k\frac{f(\omega_i,\omega_o)|\cos\theta|}{p(\omega_o)}.$$

每次到达自发光表面，累加 $\beta_k L_e$；未命中时累加 $\beta_k L_{env}$。
纯 Lambertian 材质使用余弦采样时，$f=\rho/\pi$、$p=\cos\theta/\pi$，比值化简为反照率 $\rho$。
混合光源/材质采样分支仍计算实际混合 PDF，不使用这一特殊化简。

达到默认 5 次散射后，取存活概率

$$p_s=\min(rr,\max(0.05,\max(\beta_r,\beta_g,\beta_b))).$$

若存活，将权重除以 $p_s$；否则结束路径。条件期望满足

$$\mathbb E[\beta']=p_s\frac{\beta}{p_s}+(1-p_s)0=\beta.$$

这解释了为什么不能在没有进行随机筛选时也除以 `rr`。该补偿只保证轮盘步骤不额外引入偏差，不代表既有材质模型均为严格物理模型。
代码没有硬反弹次数上限；迭代形式消除了长路径的递归栈增长。

## 3. 自适应采样：把预算留给尚未收敛的像素

像素的线性 RGB 值可写成积分 $I=\mathbb E[X]$。固定采样的估计为

$$\hat I_N=\frac{1}{N}\sum_{i=1}^{N}X_i.$$

对于独立同分布样本，均值标准误差通常估计为 $s/\sqrt N$。
但 **同一个 Sobol 序列内的点不是独立随机样本**，不能把该公式直接当成它的可靠误差估计。

### 用独立随机化副本估计误差

本实现对每个像素维护 $R=8$ 个独立数字随机移位副本。第 $r$ 个副本包含 $n$ 个样本，均值为

$$\bar X_r=\frac1n\sum_{i=1}^{n}X_{r,i},\qquad
\hat I=\frac1R\sum_{r=1}^{R}\bar X_r.$$

在每个副本样本数相等的检查点，用副本均值之间的差异估计最终均值的标准误差：

$$\widehat{SE}=\sqrt{\frac{1}{R(R-1)}\sum_{r=1}^{R}(\bar X_r-\hat I)^2}.$$

这利用的是副本之间的独立随机化，而不是错误地假定副本内部点独立。伪随机模式也使用同样的分组估计。
对有限的预定样本数，该方差估计具有标准的独立副本解释；自适应停止后不再直接享有相同保证。

每个 RGB 通道分别要求

$$2.5\widehat{SE}_c\le\epsilon_{abs}+\epsilon_{rel}|\hat I_c|.$$

- 默认 $\epsilon_{abs}=0.002$：给暗部提供绝对误差容限，避免均值接近零时无法满足纯相对条件。
- 默认 $\epsilon_{rel}=0.05$：让容限随通道亮度增加。
- RGB 分别判断，避免只看亮度时遗漏色彩噪声。
- 所有值都是 **gamma 变换前的线性 RGB**，不是 8 位 PNG 数值。

只有每个副本具有 $2,4,8,16,\ldots$ 个样本时检查，即总样本数 $16,32,64,128,\ldots$。
还必须达到 `min_samples`，并连续通过两次检查。因此默认最早在 32 个样本后停止。
`samples_per_pixel` 始终是硬上限：预算为 35 或 100 时不会被上调为 64 或 128。
停止后用真实的 $N$ 做平均，而不是用预算上限；否则提前停止的像素会变暗。

### 为什么不是“保证误差小于 5%”？

`2.5` 是保守的经验裕量，不是经过重复检验校正后的严格置信系数。
光路分布可能重尾，少量样本可能没有遇到亮焦散；反复查看统计量、按数据决定停止也会带来可选停止偏差。
因此此方法属于实用的自适应误差启发式，不能保证每个像素或整张图的最大误差。
严谨参考图应关闭自适应并使用足够大的固定预算，还要用多个独立种子评估误差。

## 4. Sobol：让相机采样在单位超立方体内更均匀

相机采样是 $[0,1)^5$ 中的点。普通独立随机点会出现局部聚集和空洞。
Sobol 是基于二进制数字网的低差异序列，在合适的 $2^m$ 点前缀中保持良好的分层覆盖。

### 二进制方向数与 Gray code

令样本序号的 Gray code 为

$$g(n)=n\oplus(n\gg1).$$

在维度 $d$，把 Gray code 中置位位置对应的方向数异或：

$$q_{n,d}=\bigoplus_{k:g_k(n)=1}v_{d,k}.$$

不同维度使用不同本原多项式生成方向数，不能在所有维度重复使用同一条一维序列。
本项目存储五维、每维 32 个方向数，并对不同像素共用的基础点做有界预计算。

### 数字随机移位

每个像素、每个副本、每个维度使用独立派生的 32 位移位掩码 $s_{p,r,d}$：

$$u_{p,r,n,d}=\frac{(q_{n,d}\oplus s_{p,r,d})+1/2}{2^{32}}.$$

异或掩码在二进制域平移数字网，保留其分层结构；随机化后单个点在离散精度范围内均匀分布。
加 $1/2$ 取离散单元中点，避免恰好 0 或 1 的端点。
这是 **数字随机移位**，不是完整的嵌套 Owen scrambling。
不同像素独立随机化，避免全图使用同一采样花纹。

样本按副本轮转：`replica = sample % 8`，`index = sample / 8`。
这使每次误差检查时，八组副本具有相同长度的 Sobol 前缀。
镜头采用连续的同心方形到圆盘映射，只消耗固定两个维度，避免拒绝采样导致维度错位。

### 为什么通常会降低噪声？

对于适当的有限变差函数，准蒙特卡洛误差可用 Koksma–Hlawka 不等式描述：

$$|\hat I_N-I|\le V_{HK}(f)D_N^*.$$

其中 $D_N^*$ 是样本的星差异，表示样本覆盖偏离均匀分布的程度。
Sobol 的目标是降低差异，而不是让某一次射线求交变快。
光线追踪有可见性跳变、复杂 BSDF 和高维散射，不满足所有平滑性假设；本项目还只在相机域使用 Sobol。
所以不能据此声称整张图必然达到 $O(1/N)$ 误差或固定倍数加速。

## 验证与性能解读

- 已有解析测试验证纯漫反射/镜面路径不再错误放大，轮盘及混合 PDF 的采样均值接近解析值。
- Sobol 测试验证已知前缀、各维一维分层、二维像素覆盖、随机化可复现和简单平滑积分误差。
- 自适应测试验证恒定像素由 128 降至 32 次采样而输出不变，复杂像素不会超预算，线程调度不影响结果。
- 当前随机球体场景在 960x540、最大 256 次采样时，自适应实测平均约 197.5 次/像素，约少 22.9% 路径起点。
- 同机连续测试的墙钟时间波动明显，不能把样本节省比例直接称为加速比，也尚未据此证明整幅图达到相同误差。

比较质量应看固定时间下的线性 RGB 误差，或达到给定误差需要的时间，而不是只比较采样数和 PNG 文件大小。
