## 编辑器环境说明

用户全局 `clangd.fallbackFlags` 包含 `-std=c++23`，会让 C 包装出现“C 不允许 C++23”的编辑器诊断。
[工作区配置](../.vscode/settings.json) 已局部改为 `-std=c17`，不修改用户全局设置。
已启动的 clangd 可能保留旧参数，需要执行编辑器的 **clangd: Restart language server** 或重新加载窗口。
最终 Zig 构建及严格 C 编译均已通过；缓存的编辑器诊断不等同于构建失败。
